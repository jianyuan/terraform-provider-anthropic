# anthropic_workspace_member (Data Source)

Get information about a Workspace Member.

Requires an Admin API key: set `api_key` in the provider block or the `ANTHROPIC_API_KEY` environment variable. OAuth bearer tokens (`auth_token`) are not used.

## Example Usage

```terraform
data "anthropic_workspace_member" "example" {
  workspace_id = "wrkspc_xxxxx"
  user_id      = "user_xxxxx"
}
```
